# AI Basics Chatbot Lab — outcomes

## Working rule-based chat lesson
- [x] Provide an interactive chat interface where a learner can send messages and receive replies from a working rule-based chatbot.
- [x] Match simple keywords to readable replies, show the matched rule, and use a clear fallback when no rule matches.
- [x] Keep conversation history visible so the learner can see how prior turns can be carried forward as context.

## Language-model connection walkthrough
- [x] Show a clearly commented language-model connection example with a system instruction, user prompt, conversation history, request shape, and response handling.
- [x] Keep the frontend-only demo safe: it explains the server-side integration point without requiring or exposing an API key.

## AI concepts tied to code
- [x] Explain, briefly and in-app, what a language model is, prompts versus system instructions, tokens, multi-turn context, and hallucinations.
- [x] Tie each explanation to a named constant, function, or visible UI element in the code.

## Learning path
- [x] End with next steps for adding a persona and a dedicated knowledge source.
- [x] Ask how comfortable the learner is with coding and offer simpler or deeper follow-up guidance.
